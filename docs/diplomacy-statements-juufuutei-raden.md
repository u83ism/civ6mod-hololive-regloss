# 儒烏風亭らでん 外交交渉画面の台詞(案)

**すべてAIの案であり、本人は未確認**(`.claude/rules/documentation.md`)。本人の指摘を右端の列に書き、直しながら確定させていく。確定したブロックは節の見出しに「(確定)」と付ける。確定したものから`Text/ja_JP/Text.xml`に実装する。他言語(en/zh)は日本語が固まって本人が指示するまで作らない(`.claude/rules/localization-order.md`)。

- 人物像の根拠・口調の出典: [character-juufuutei-raden-personality.md](character-juufuutei-raden-personality.md)。場面の意味(誰が誰に言う台詞か): `.claude/skills/implement-diplomacy-statements/references/diplomacy-statement-schema.md`
- タグ表記は`LOC_DIPLO_<場面>_LEADER_REGLOSS_JUUFUUTEI_RADEN_ANY`の`<場面>`部分だけを書く(`KUDO_LEADER_ANY_REASON_AGENDA_*`と`MODIFIER_*`は別扱い。末尾の節)
- 「らでん」は自称、相手は「あなた」。口調は落語家調の丁寧語を基調にし、**感情が動く場面だけ博多弁**(「〜けん」「どげんしたとですか」)を出す
- ゲーム内の吹き出しなので、1〜2文、長くても80字程度に収める。UIで切れる場合は短くする
- 口癖は[パーソナリティ調査](character-juufuutei-raden-personality.md#口癖決まり文句語録ページ)で、wikiに載っているものだけを使った。「おあとがよろしいようで」だけはwikiに無い一般的な落語の締め

## アジェンダ関連の台詞(不要の見込み)

莉々華は専用アジェンダの文言として`LOC_DIPLO_KUDO_LEADER_ANY_REASON_AGENDA_*`・`LOC_DIPLO_WARNING_LEADER_ANY_REASON_AGENDA_*`・`LOC_DIPLO_MODIFIER_*_LIKES_PEACE`/`DISLIKES_WAR`を持っているが、らでんのアジェンダはバニラの「文化重視」(`TRAIT_AGENDA_PREFER_CULTURE`)をそのまま指しているので、これらの文言もバニラのものが使われる見込み(AIの推測)。**実機で確認し、バニラの文言が出なければ追加する**。
