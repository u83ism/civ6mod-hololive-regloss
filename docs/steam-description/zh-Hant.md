# Steam Workshop 說明文(繁體中文)

`ja.md`(正本)的翻譯。請先更新`ja.md`，再把差異部分翻譯到這裡(不要單獨修改本文件)。更新後請手動複製到Steam的編輯頁面(沒有自動同步)。

寫法・更新步驟請參考`write-steam-description` Skill。

---

這是一款以hololive ReGLOSS為主題追加新文明的MOD。

【開發中】
目前僅實裝了一條莉莉華(一條公司)。可能存在殘留的bug，如有發現請在評論中告知。

【支援語言】
支援日語、英語、簡體中文、繁體中文文本。日語以外的文本均借助Claude(AI)翻譯，可能包含不自然的表達或錯誤，歡迎指正。

【平衡性說明】
本MOD設計為與HktkNban的Hololive JP Mod、Neox的Hololive EN/ID Mod搭配使用，因此單獨來看強度偏高(有些超模)，以便與其他作者的MOD文明放在一起時不會被埋沒。

【一條莉莉華(一條公司)】

文明專屬能力「見習秘書們的奮鬥」
資源地塊已開發時，加成資源額外獲得金幣+3，戰略資源+4，奢侈品資源+6。建造者的使用次數上限比通常多1次。

領袖專屬能力(預設)「追星辛苦了～」
同時擁有市場和燈塔的城市貿易路線上限+1。來自貿易路線的食物+1、生產力+1、科技值+1、文化值+1。

領袖專屬能力(壟斷與企業模式)「大天才」
工業額外獲得文化值+2、科技值+2、金幣+1。企業的這些加成全部翻倍。商品項目的生產力+100%。

專屬議程「KPG」
親近不好戰的文明，討厭好戰的文明。
(隱藏效果，與亞歷山大大帝的議程機制相同：她對其他文明的不滿(Grievance)衰減速度也會加倍。)

專屬單位「海膽」(社長的愛犬)
取代偵察兵的一條公司專屬遠古時代偵察單位。移動力+1。

今後，ReGLOSS的其他成員也計劃陸續加入本MOD。
