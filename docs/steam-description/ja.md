# Steam Workshop 説明文(日本語)

Steam Workshopの掲載ページに掲載する説明文の**正本**。日本語版を先に更新し、`en.md`・`zh-Hans.md`・`zh-Hant.md`はこのファイルをテンプレートとして翻訳する(独立に書き換えない)。更新後はここから本人が手動でSteam側の編集画面にコピペする(自動反映はしない)。

書き方・更新手順は`write-steam-description` Skillを参照。

---

hololive ReGLOSSをモチーフにした新しい文明を追加するMODです。

【開発中です】
現在実装済みなのは一条莉々華(一条コーポレーション)のみです。バグが残っている可能性があります。気づいた点があればコメントで教えてください。

【対応言語】
日本語・英語・簡体字中国語・繁体字中国語のテキストに対応しています。日本語以外のテキストはClaude(AI)の助けを借りて翻訳しており、不自然な表現や誤りが含まれている可能性があります。指摘は歓迎します。

【バランスについて】
HktkNban氏のHololive JP Mod、Neox氏のHololive EN/ID Modと混ぜて使うことを想定しているため、単体で見るとやや強め(オーバーパワー気味)の調整にしています。

【一条莉々華(一条コーポレーション)】

文明固有能力「秘書見習い達の奮闘」
資源タイルが開発済みの場合、ボーナス資源はゴールド+3、戦略資源は+4、高級資源は+6追加で得る。労働者の使用回数制限が通常よりも1回増加。

指導者固有能力(通常時)「推し事お疲れ様でした～」
市場と灯台の両方がある都市は交易路の上限+1。交易路からの食料+1、生産力+1、科学力+1、文化力+1。

指導者固有能力(独占・大企業モード時)「大天才」
産業は追加で文化力+2、科学力+2、ゴールド+1を得る。大企業はそれらがすべて2倍になる。商品プロジェクトの生産力+100%。

ユニークアジェンダ「KPG」
好戦的でない文明を好み、好戦的な文明を嫌う。
(隠し効果、アレクサンドロス3世のアジェンダと同じ仕組み: 自分が他文明に対して抱く不平の減衰速度も2倍になる。)

ユニークユニット「うに」(社長の愛犬)
斥候に取ってかわる、一条コーポレーション固有の太古の偵察ユニット。移動力+1。

今後、ReGLOSSの他メンバーもこのMODに順次追加予定です。
