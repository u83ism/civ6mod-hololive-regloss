# Steam Workshop 说明文(简体中文)

`ja.md`(正本)的翻译。请先更新`ja.md`，再把差异部分翻译到这里(不要单独修改本文件)。更新后请手动复制到Steam的编辑页面(没有自动同步)。

写法・更新步骤请参考`write-steam-description` Skill。

---

这是一款以hololive ReGLOSS为主题追加新文明的MOD。

【开发中】
目前仅实装了一条莉莉华(一条公司)。可能存在残留的bug，如有发现请在评论中告知。

【支持语言】
支持日语、英语、简体中文、繁体中文文本。日语以外的文本均借助Claude(AI)翻译，可能包含不自然的表达或错误，欢迎指正。

【平衡性说明】
本MOD设计为与HktkNban的Hololive JP Mod、Neox的Hololive EN/ID Mod搭配使用，因此单独来看强度偏高(有些超模)，以便与其他作者的MOD文明放在一起时不会被埋没。

【一条莉莉华(一条公司)】

文明专属能力"见习秘书们的奋斗"
资源地块已开发时，加成资源额外获得金币+3，战略资源+4，奢侈品资源+6。建造者的使用次数上限比通常多1次。

领袖专属能力(默认)"追星辛苦了～"
同时拥有市场和灯塔的城市贸易路线上限+1。来自贸易路线的食物+1、生产力+1、科技值+1、文化值+1。

领袖专属能力(垄断与企业模式)"大天才"
行业额外获得文化值+2、科技值+2、金币+1。公司的这些加成全部翻倍。商品项目的生产力+100%。

专属议程"KPG"
亲近不好战的文明，讨厌好战的文明。
(隐藏效果，与亚历山大大帝的议程机制相同：她对其他文明的不满衰减速度也会加倍。)

专属单位"海胆"(社长的爱犬)
取代侦察兵的一条公司专属远古时代侦察单位。移动力+1。

今后，ReGLOSS的其他成员也计划陆续加入本MOD。
