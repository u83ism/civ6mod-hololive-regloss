# 儒烏風亭らでん パーソナリティ調査(外交台詞執筆用)

外交交渉画面の台詞をキャラクター性格ベースで書くための調査メモ。出典はseesaawiki「ホロライブ非公式wiki」の儒烏風亭らでんページと、その下位ページ「語録」(2026-10-05取得。本ページの最終更新は2026-09-08の版)。EUC-JPなので、curlで生HTMLを取得してデコードして読んだ(要約ツールは使っていない)。**非公式Wikiであり、配信内言動のリスナーによるまとめなので、一次情報(本人の配信)との食い違いがあれば実際の配信の方を優先すること。** 設計上の判断は[design.md](design.md)の「儒烏風亭らでん」節、台詞案は[diplomacy-statements-juufuutei-raden.md](diplomacy-statements-juufuutei-raden.md)。

## 公式紹介文

> 「ちょいと一席付き合ってみませんか？」伝統と革新に身を包み、落語家に浪漫を抱くおばあちゃん子。新旧和洋を問わず文化・芸能を愛しており、美術館通いの結果、金欠気味の日々を過ごしている。決してお酒の買いすぎが原因ではない。落語と出会ってからはより話すことが好きになり、噺作りにも挑戦中。

- 紹介文の「ちょいと一席付き合ってみませんか？」はそのまま台詞に使える(初対面・あいさつ向き)
- 自己紹介: 「ホロライブDEV_ISよりデビューいたしました、ReGLOSSは神出鬼没のミュージアムプリンセス担当、儒烏風亭一門は前座見習い、儒烏風亭らでんでございます！」(2025年秋〜冬から。旧: 賑やかし・ネタ枠担当)
- コールアンドレスポンス: (先)神出鬼没のミュージアムプリンセスといえばっ?(後)らでんっ!!

## 性格の核

- **学者気質+アーティストの感性の知識人**。あらゆるものに疑問・興味を持ち、実際に学びに行く・体験しに行く行動力がある(「森羅万象のオタク」)。建物や草花、ゲームの中の建築様式にまで反応する
- **雄弁家**。噺家(前座見習い)らしく滑舌が良く、早口でも聞き取りやすい。マシンガンフリートーク、話が突然豆知識コーナーになる。説明は「誰にでもわかりやすく」
- **ボケを愛するが、周囲からは常識人と見られている**。活動初期は「酒カス・ヤニカス・スロカスのカスの大三元」を名乗る破天荒キャラだったが、実際は常識・モラルがあり、ツッコミやフォローも器用にこなす。本人は「ネタ枠なの!」と抵抗するが、2025年秋からは「ミュージアムプリンセス」を名乗って腹を括った
- **丁寧で感謝を忘れない**。登録者10万人の時は無邪気にはしゃいだ後、「らでんの力ではありません。先輩方のおかげです」と丁寧に述べている。先輩との距離感・立ち回りが上手い
- **気にしい・真面目**。能面で初配信した理由は「顔と声が合っていないと言われるのが怖く、先に声に慣れてもらおうと思った」
- **かわいいもの好き**(ポムポムプリンのぬいぐるみ約90体。ただし**版権要素は使わない**と本人が決めている。design.md)
- **お酒が強く、酒との付き合いが上手い**。配信中でも「お酒を飲みマァス!」。合間にチェイサーを挟む。同期の莉々華の介護役になりがち
- **ゲームは最弱クラス・絶叫系は苦手・血圧測定で気分が悪くなる**。**歌には苦手意識**がある
- 配信者とリスナーの関係は健全で、尊敬されるタイプ。例えるなら「明るくて生徒との距離が近く、授業も面白いと人気の美人教師」(wiki)

## 話し方・口調

### 基本(配信での丁寧語)
- 配信開始: 「はい！ 皆さんこんばんは～ 声は聞こえておりますでしょうか！」。自己紹介は「〜でございます！」と落語家調
- 視聴者への呼びかけは「皆様」「皆さん」。自分のことは**「らでん」**と呼ぶ(呼称一覧の一人称欄: らでん、私、オレ、儂(わし))。先輩は「〜先輩」、同期はあだ名・ちゃん付け
- 乾杯の音頭は口上が長い。「お酒が飲める環境の方はぜひ一緒に飲んでいただければと思います。…目の前に飲み物が何もないという方は空気中の水分をかき集めてどうにかこうにか飲めるかたちにしてください!」(落語家として話で人を惹きつけたい姿勢)

### 方言
- wikiの記述: 「〜っちゃん」「〜けん」などの**方言喋り**。**博多弁をベースに鹿児島方面の方言が混ざっている**。福岡出身(実家が福岡)、祖母は鹿児島方面の出身で、「言葉が北とも南とも定まらない」のは祖母の影響(祖母は能面のサムネ配信を見て連絡してくるほどの「らでばあ」)
- 語録ページに確認できる実例: 「**どげんしたとですか!?**」(福岡の方言。wikiに「現地以外ではなかなか聞けないのでレア」とある)
- **常に方言で話すわけではない**。配信は丁寧語が基本で、方言は感情が動いた時・くだけた場面に出る、という前提で台詞に混ぜる(AIの解釈)
- 語録ページの引用「あんたも云百万を東博御中に寄付されるとか、大衆が簡単にできるものじゃ無いばい?」(2026-03-21の配信のタイトルと並んで載っているが、話者は未確認。らでんのものとは断定できない)
- 「〜ばい」「〜たい」はらでん本人の確認が取れていないので、使うなら本人判断

| 文言 | 場面 |
| --- | --- |

## 台詞に生かせる素材

- **学芸員**(国家資格)、美術館でのアルバイト・ボランティア解説員、現代アートのアーティスト、元々は写真。遺跡の発掘・遺物の保護に厳しい立場を取らせやすい(固有ユニット「学芸員」もある)
- **美術館通いと金欠**(公式)。取引を断る理由に使える
- **旅行好き**(フラッと出かける)。国境開放・使節団・大使館の台詞に使える。「らでんの旅ぷらん」という曲もある
- **日本酒・乾杯**。同盟(盃を交わす)に使える
- **落語**: 前座見習い。好きな噺は転失気・芝浜・青菜。噺作りに挑戦中。小噺風の言い回し(「さしすせそ」「ねっとりテラシー」)もある
- **ときのそら(そらでん)、アキ・ローゼンタール(アキらでん)など先輩・友人**。外交の相手は先輩ではなく他文明のリーダーなので、この関係は直接使わない
- **螺鈿**(名前の由来。黒漆蝶蜻蛉波蒔絵螺鈿箱を第二回初配信で説明した)。「ちょうちょが飛んでてきれいだなぁ、トンボが飛んでて雅だな」というフレーズが待機画面の音MADなどで定着している
- **能面**: 初配信で被った。文明アイコンの図案に使っている

## 避けるもの

- **下ネタ**。本人に「儒烏風亭ライン」(曖昧もっこり股間若衆を越えたらアウト)があり、自発的には言わない。ゲームテキストには入れない
- **タバコ**(現在は発声への懸念から辞めている。wikiの記述)。「ヤニカス」ネタも入れない
- **ポムポムプリン**(版権。本人判断、design.md)
- **「カスの大三元」**: 活動初期の自称で、現在は「全てのカスが消滅している」(wiki)。台詞には使わない(AIの判断)
- 本人は**歌が苦手**・**ゲームが最弱**なので、これらをバカにする方向の台詞は不自然

## 外交台詞への反映方針(AIのたたき台)

- 基調は**落語家調の丁寧語**(「〜でございます」「〜ですな」「まぁそんなとこですな」)。相手は「あなた」と呼ぶ。自称は「らでん」
- **感情が動く場面(宣戦布告・怒り・驚き・拒否)で博多弁を出す**(「どげんしたとですか」「〜けん」)。普段は出さない
- **戦争は苦手そうな常識人**。宣戦布告は「堪忍袋の緒が切れた」型で、いきなり攻撃的にせず丁寧な言葉遣いが残る(本人の穏やかな性格の反映)
- 取引拒否は**金欠**ネタ、遺物の発掘への警告は**学芸員**の本気の怒り、国境開放・大使館は**旅好き**、同盟は**盃**(日本酒・一門)
- 良いことがあった時は「ああぁぁぁいいい!」、諦める時は「そんな日もあるわな」
